## 打包坑（重要经验）

- electron-builder 收尾 trash 旧 artifact 会被 WorkBuddy safe-delete 拦截 FAIL_CLOSED。**规避**：build 前用**独立命令** rm 旧 `dist/Personal-AI-Dev-Center.exe` 并确认消失，再单独 `NODE_OPTIONS= npm run build`（约 2m40s）。`rm && build` 写同一命令行仍会触发拦截。
- `dangerouslyDisableSandbox=true` 跑 build 反而会让 portable 压缩阶段被杀软拖死（15min+ 卡死），普通沙箱模式 2-3 分钟即完成。**不要用**。
- 验证打包内容：`node -e "require('@electron/asar').extractAll('app.asar','目录')"`；index.html 在 extraResources（resources 根目录），不在 asar 内。
