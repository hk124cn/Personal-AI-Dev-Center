### 踩坑：grep 在 bash 里被引号吃掉

`grep -o "renderKnowledge[A-Za-z]*|openKb[A-Za-z]*" index.html` 返回**空**，一度以为知识库前端没做。
真因：管道符 `|` 落进 Windows 下 `findstr` 风格解析，命令实际跑成了两个 pattern 不带 `|` 的 grep。
→ **教训：在这台机的 Git Bash 里，`grep -o "a|b"` 的 alternation 不可靠，改用多个 `grep -n <单个词>` 或走 Grep 工具。**
差点把「已实现」误判成「未实现」去做重复劳动。
