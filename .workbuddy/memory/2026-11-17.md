# 2026-11-17

## 支持「仅本地项目」（不部署到任何服务器）

### 问题

用户想把**只在本机的项目**也纳入统计。查下来发现**数据模型里根本没有「本地项目」这个概念**：

- 17 个项目**全部**绑定了 `server` + `remote_path`
- `config.json` 的真实 servers 里**没有 `local`**（前端示例数据里那个「本地 Win11」是假的，不在配置里）
- 真实服务器 6 台：成都 / 上海 / GCP 小鸡 / 腾讯云首尔 / 阿里云新加坡 / conoha 木の葉

**「统计不进来」的机制性原因**（`index.html` 1908-1910）：

```js
const groups={};state.servers.forEach(s=>{groups[s.id]={server:s,projects:[]}});
state.projects.forEach(p=>{if(groups[p.server])groups[p.server].projects.push(p)});
```

`if(groups[p.server])` —— **没有对应服务器的项被静默丢弃**（分组视图里直接消失）。

### 各处口径（改动前）

| 位置 | 现状 | 本地项目 |
|---|---|---|
| 首页项目数 | `state.projects.length` | ✅ 自动计入 |
| 卡片视图 | `state.projects.map` 不过滤 | ✅ 能显示 |
| **分组视图** | `if(groups[p.server])` | ❌ **被丢弃** |
| **新增项目表单** | 服务器下拉只有 6 台云主机 | ❌ **根本录不进来** |
| 同步/监控/跑分 | 按服务器遍历 | 自然跳过（合理） |

### 改动（4 处 + 后端 2 处）

1. **表单**：服务器下拉加「本地（仅本机，未部署）」选项（`value: ''`）
2. **分组视图**：`groups['']` 单独一组，标题「本地项目」
3. **项目卡片**：server 为空时右下角显示「本地」徽章（原来是 `-`）
4. **卡片按钮**：本地项目**只保留「本地分析」**，去掉下载/上传
   —— 下载/上传是「和远端交互」，本地项目没有远端，点了必然报错
5. **后端 add_project**：`remote_path` 不再回退成 `project.id`
   （原来会给本地项目造一个根本不存在的远端目录，后续同步/上传对着它报错）
6. **后端 update_project**：同样的问题，一并修

**同步不用改** —— `sync_all` 里已经有 `if server_id not in servers: continue` ✅

### 验证（真实 HTTP + 真实浏览器，6/6）

```
PASS  能保存 server 为空的项目 -> HTTP 200
PASS  项目在 config 里
PASS  server 存成空串 -> ''
PASS  remote_path 没有被填成 id（不造假路径） -> ''
PASS  local_path 保留 -> D:\app\local-test-proj

```

右下角「本地」蓝色徽章 + 本地路径，右上角**只有 1 个按钮**（本地分析 ✨），
其他云主机分组是 3 个按钮（⬇⬆✨）。

### 踩到的坑

  **禁动画**（`* { animation:none!important; transition:none!important }`）+ 冻结定时器。
  这次忘了，但 DOM 断言已经验证通过，属于「截图不清晰」而非功能问题。

### 还没做的：本地项目参与跑分

**跑分是「机器维度」**，不是项目维度 —— 跑分评估页按 `state.servers` 组织。
本地项目没有服务器 → 不进那张表。

而且**本机跑不了 Linux 基准**（fio / sysbench / iperf3），`steal time` 更是
Windows 根本没有的概念（除非是 Hyper-V 虚拟机里的来宾系统）。

要做的话是另一套东西：Windows 版轻量体检（PowerShell 测 CPU/内存/磁盘），
结果**单独一档标注「本机自测，不与云主机横向对比」**。已问用户，暂未确认。
