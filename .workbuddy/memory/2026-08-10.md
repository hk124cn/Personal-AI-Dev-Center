## 同步范围选项（智能过滤 vs 全部文件）(v1.4.17)
- 背景：用户下载 AUTO-STOCK 发现只有 1865 个文件 → 定位到 sync.py 两层过滤：目录级 `DEFAULT_SYNC_IGNORE`(.git/node_modules/venv/.idea/.vscode/.DS_Store/Thumbs.db/__pycache__) + 扩展名 `DEFAULT_SYNC_IGNORE_EXT`(.csv/.log/.zip/.exe 等)。**.csv 被过滤对数据类项目是误伤**（股票数据全是 csv）。
- 结论给用户：过滤动机是速度/体积（可再生/产物文件），不是安全；csv 那条是「同步代码不同步数据」的启发式。
- 实现（用户选了「每次点击时选范围，默认智能过滤」方案）：
  - sync.py：`_local_stat_tree` / `_sftp_stat_tree` / `_remote_stat_tree_fast` / `sync_download` / `sync_upload` 全部加 `sync_all=False` 参数；True 时跳过所有过滤。注意 sync_upload 循环里还有一处 `_should_ignore(rel)` 也要跳过（否则选中的 csv 仍被丢）。
  - app.py：`/api/sync-download/{id}`、`/api/sync-upload/{id}`、`/api/project-files/{id}` 都加 `all` query 参数（`all=='true'` → sync_all）。
  - 前端：下载点按钮 → 先弹范围选择卡（智能过滤=默认选中 / 全部文件），确认才 `runSyncWithProgress(..., syncAll)`；上传弹窗顶部嵌同款选择卡，切换时 `setUploadScope` 重新拉预览（`window._uploadScope` 记忆本次选择）；`all=true` 拼进 URL。
  - CSS：`.scope-opt` 选择卡（`:has(input:checked)` 高亮，Electron 33 支持）。
- 验证：`_local_stat_tree` 实测——默认滤掉 data.csv 和 .git/；sync_all=True 全保留。JS/Python 语法均过。
- README 中英双版同步机制一节已补「两种范围可选」。
