### ⚠️ 先更正昨天的一个误判

昨天写「监控历史没接前端」是**错的**。真相：前端**早就接了** —— 历史数据是
`/api/monitor/{id}` **返回体里的 `history` 字段**带回来的，绘图函数叫 `drawMonChart`，
由 `pollMonitor()` 消费。独立的 `/api/monitor/{id}/history` 端点只是冗余。
昨天「零命中」是因为我只 grep 了 `/history` 这个**路径字符串**，没 grep 字段名/函数名。
→ **教训：查「某功能接没接」要按字段名 + 函数名搜，别只搜端点路径。**

所以 P1 从「新建曲线」改成「**增强既有曲线**」。

### P1 监控图表增强（v1.4.22）

改造内容：
- 单曲线（仅 CPU）→ **多曲线**：CPU + 内存默认开，磁盘默认关（磁盘变化太慢，会把 CPU/内存压扁），
  点图例切换；图例高亮以 `_monSeriesOn` 为唯一真源。
- 颜色**全部**改从 CSS 变量取（`cssVar()` / `colorWithAlpha()`），不再硬编码。
- 副标题按**真实采样点跨度**动态计算（首页监控也是同一份 history，间隔不固定，写死「约 1 小时」是假的）。
- Y 轴 % 刻度从**右边缘**挪到**左侧 30px 装订线** —— 原来贴在右边会和曲线末端叠在一起。

修掉的三个真 bug：
1. **浅色主题色盲**（原定目标）：原 `drawMonChart` 硬编码 `rgba(26,26,38,.96)` 气泡底、
   `rgba(150,150,175)` 轴文字、`rgba(255,255,255,.06)` 网格 → 在「明亮白」主题下**完全看不见**。
2. **浅色主题下黄线在白底不可见**（顺手发现）：`--amber`(#eab308) 在浅色主题里没有被覆盖，
   黄线画在白底上等于隐身。新增图表专用变量 `--mon-cpu/--mon-mem/--mon-disk`，
   用 `html[data-theme="light"]{--mon-mem:#b45309;--mon-disk:#2563eb}` 覆盖
   （**用 `html[...]` 而不是 `[...]`**，特指度 0-1-1 才压得住 `:root` 的 0-1-0，顺序无关）。
3. 气泡背景/描边/文字也都走变量，浅色下是白底+灰边+深字。

验证：`tools/gen_mon_variants.py` → 5 个变体（深色 / 浅色 / 三线全开 / 浅色悬停 / 深色悬停），
`tools/shot_variants.py` 批量无头截图，**5/5 READY**，逐张肉眼确认过。
结论：浅色主题下 CPU 紫线、内存深琥珀线、蓝磁盘线、网格、Y/X 轴刻度、悬停气泡**全部清晰可见**。
