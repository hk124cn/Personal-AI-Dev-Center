## 关键现状（交接要点）
- **不是 git 仓库**：整个目录无 .git / .gitignore，无版本控制。发布仅靠 electron-builder 打 exe。
- **发布流程**：`npm run build`（portable，产出 dist/Personal-AI-Dev-Center.exe ~75MB）或 `npm run build:setup`（NSIS 安装包）。今天 dist_new/ 里有一份刚构建的 exe（07-26 18:47）。
- **运行方式**：`pip install -r backend/requirements.txt` → `python backend/app.py`（监听 localhost:8765，serve index.html）。Electron 外壳会 spawn 该 python 进程。
- **数据/配置**：config.json 是服务器/项目清单的 source of truth；同步结果写入 backend/data/latest.json。打包后首次运行会把 config.json 复制到 %APPDATA%/Personal AI Dev Center/。
- **安全注意**：config.json 内含真实服务器 IP、SSH key 路径、LLM API Key（商汤 SenseNova），会被打进 exe 并随首次启动写入 APPDATA → 密钥随安装包扩散，需要后续处理。
- **版本号漂移**：真实版本 1.4.11（package.json / health / index.html APP_VERSION），但 electron/main.js「关于」弹窗和 FastAPI app.version 仍写死 1.0.0。
- **无自动同步调度**：后端没有 scheduler；前端每 5 分钟只刷新 dashboard 数据（读 latest.json），同步本身是手动（UI 按钮 / POST /api/sync / CLI `python backend/sync.py`）。docs 提到“定时任务”但实际未实现。
- **latest.json 已过期**：最后同步 2026-07-20，含 15 个项目；当前 config.json 只剩 12 个（少了「自动抓取资讯网站 / 打字游戏 / 拼音学习乐园」），下次同步会丢失这 3 个历史数据。
- **文档陈旧**：docs/ 仍推荐 Anthropic/OpenAI/Qwen 且写 `sync.py --project`（参数不存在）；实际 config 用商汤 SenseNova（走 OpenAI 兼容分支）。llm_analyzer.py 无独立 sensenova 分支，靠 base_url 走 else 分支。
