## 用户疑问：定时同步后"项目的未更新日期"没变，效果在哪看
根因（已对照代码确认）：
- `lastUpdate`（内容更新时间）= 来自远程 Markdown 内容里的"最后更新"行（`index.html:3914/3968` 取 `apiP.progress.last_update`）。只有当**服务器上的文件内容真的被改过**它才变。
- `_syncedAt`（同步刷新时间）= 同步引擎每次运行写 `datetime.now()`（`sync.py` 多处 `synced_at`；前端 `index.html:3922/3975` 取 `apiP.synced_at`）。
- 侧栏"内容 X 天未更新"告警由 `computeAlerts`（`index.html:1405`）按 `lastUpdate` 算 → 所以内容没改，这日期/天数不变是**预期行为**，非 bug。
- 这正是 #99 刻意分离的两个概念：定时同步=重新拉取（刷新），内容没动→"内容更新"不动，但"同步"时间前进。
