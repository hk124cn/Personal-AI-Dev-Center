# 2026-08-30 工作日志

## 端口 8765 被孤儿后端占用 / 退出自动关端口（commit 56a0125）
- **现象**：用户先双击老的 `D:\tmp\Personal-AI-Dev-Center-Dev-old.exe`，退出后 `devcenter-backend.exe`(PID 39288) 孤儿存活占 8765；新 exe 检测即弹「已在运行」退出，用户不知如何关端口。
- **即时处理**：沙箱与本机同环境，`netstat` 可见 39288；`PowerShell Stop-Process -Id 39288 -Force` 杀掉孤儿后端，端口释放（经验证 8765 空闲、无残留）。
- **根因**：旧 `killBackend()` 用 `spawn('taskkill'…)` 异步强杀，electron 先走完退出流程 → 后端未死成孤儿。
- **修复（56a0125）**：`killBackend()` 改 `execSync('taskkill /PID <pid> /T /F')` 同步杀自己 spawn 的后端树；挂 `before-quit` + `app.on('quit')` + `process.on('exit')` 三重兜底；「已在运行」提示框内直接附 `Stop-Process -Name "devcenter-backend" -Force` 让用户知道怎么手动关。
- **部署**：`npm run build`(6m4s, 无报错) 重建 `dist/Personal-AI-Dev-Center.exe`，并 `cp` 覆盖 `D:\tmp\Personal-AI-Dev-Center-Dev-old.exe`，两份均带新逻辑（96,257,272 字节，Aug 30 00:18/19）。
- 构建前按 SOP 先 `Stop-Process` 清掉上次残留的 node.exe(25244/28296) 以防锁 dist。
