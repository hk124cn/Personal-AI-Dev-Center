## 4. ⚠️ electron-builder 打包卡死坑（重要，新增）
- **现象**：`dist/` 里若已存在旧 96MB exe，重新 `npm run build` 会卡在 `packaging` 阶段 10+ 分钟无进展（win-unpacked 复制完成但不进入压缩、Dev/目标 exe 始终不生成）。
- **根因**：electron-builder 打包前清理 outputsDir 时，杀软正实时扫描那个刚生成的旧 96MB exe，删除被阻塞 → 卡死。（主力版那次 `dist` 为空所以 2m53s 过。）
- **解决**：打包前把旧 exe **移出 `dist/`**（同盘 rename 到 `D:/tmp` 秒级，避开杀软锁），保持 `dist/` 根无 exe，再 build → 2-3 分钟过。验证：Dev 版卡 12m50s 被杀，移走主力 exe 后重打 2m14s 成功。
- **教训**：每次 `npm run build` 前确保 `dist/` 根无同名/旧 exe；有则先 rename 移走，不要依赖 electron-builder 自动清理。
